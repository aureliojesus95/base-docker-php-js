# Objetivo

A ideia desse repositório é criar um ambiente de desenvolvimento PHP + JavaScript simples e objetivo, adicionando novos novas dependências de acordo com a necessidade.

A pessoa poderá clonar este repositório, alterar o nome "base" para o nome de seu projeto atuar e possuirá um ambiente de desenvolvimento PHP + JavaScript completo, sem precisar instalar nenhuma dependência de linguamge de programação na própria máquina.
